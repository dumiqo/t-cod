# 23.4 Наблюдаемость

- на каждого продвинутого после коммита — событие с `waitlistId`, `enrollmentId` и местами,
  `club.waitlist.promoted` и `club.visits.charged`;
- пропуск ожидающего из-за абонемента (задача 21) — событие с `waitlistId` и причиной
  `pass-exhausted` / `pass-expired`, без метрики; пропуск из-за мест не логируется;
- при `503` и откате продвижения событий нет;
- тесты гонок 23.3 дополнить, как в 8.4: число событий продвижения равно числу продвинутых
  в базе.
