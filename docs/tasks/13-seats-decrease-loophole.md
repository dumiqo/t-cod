# 13. Исследование: лазейка с уменьшением мест

Статус: проработано

Уменьшение (§2) возвращает разницу без правила двух часов. За час до начала бронь на 5 мест:
отмена вернёт 0 посещений, а «уменьшить до 1, потом отменить» вернёт 4. Контракт возврат
разницы задаёт явно.

Варианты: принять по контракту и описать в заметках; применять правило двух часов
к уменьшению — расходится с контрактом.

Решено при разборе:

- принять по контракту: уменьшение до начала занятия возвращает разницу полностью, правило двух
  часов к нему не применяется. Свой отказ и возврат 0 расходятся с §2;
- `refundedVisits` отмены после уменьшения — только то, что вернула сама отмена;
- в коде 14.1 — пометка `// решение:` у возврата разницы; тесты — в 14.2;
- наблюдаемость без нового события и поля: злоупотребление — уменьшение, затем 2003 по той же брони;
- места, освобождённые поздним уменьшением, — по решениям задач 21 и 22.

Решение — в заметках, раздел «Лазейка с уменьшением мест».
