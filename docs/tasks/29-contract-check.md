# 29. Проверка по контракту

- на каждую строку каждой таблицы кодов и причин — тест;
- на общие правила, которых в таблицах нет: `401` без токена и с недействительным токеном
  на всех восьми эндпоинтах, `429`, игнорирование неизвестных полей тела, отказ без следов;
- сценарии на сидах на чистой базе:
  - занятия с 0, 1 и 2 свободными местами;
  - занятия, которые начнутся через 20–115 минут: фейковые часы стоят на моменте засева шаблона
    (решение задачи 5), поэтому это ровно 20–115 минут по часам теста;
  - занятия с одинаковым временем начала;
  - пользователь с двумя бронями по одному месту на одно занятие;
  - активные брони на отменённых занятиях;
  - абонементы с 0 и 1 посещением и просроченные;
- ручная проверка скорости на синтетической базе: в сидах 200 занятий и около 300 броней;
- ручная проверка с остановленным Redis.
