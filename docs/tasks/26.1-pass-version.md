# 26.1 Версия абонемента

Статус: проработано

По решению задачи 25 (заметки, раздел «Кэш карточки»). Кэша здесь ещё нет — только версия
в базе, тесты на её состояние.

- миграция `passes.version bigint NOT NULL DEFAULT 0`, `Pass.Version`; сид оставляет `0`.
  Приложение стартует на чистой базе;
- `GetVersionedCardAsync` → `VersionedCard(Card, Version)` тем же одним SELECT, что
  `GetCardAsync`; репозиторный тест: версия совпадает с базой, чужая бронь — `null`;
- версию поднимают на `+1` в своей транзакции: §1 — автору, §2 при изменении числа мест (в обе
  стороны) — автору, §3 при настоящей отмене (с возвратом и меньше чем за 2 часа, когда остаток
  не меняется; и на отменённом клубом занятии) — автору, продвижение — каждому продвинутому,
  один раз за операцию, сколько бы его записей ни продвинули;
- тест на каждый случай «не поднимает»: каждый `409` §1, §2, §3, `503` (откат), повтор §1
  по ключу, §2 с тем же числом мест, повтор §3, §7, §8, пропуск при продвижении (`own-release`,
  `pass-exhausted`, `pass-expired`, нет мест) — версия пропущенного прежняя;
- результаты `Created`, `Cancelled`, `Changed` несут новые версии затронутых пользователей
  (`userId → version`) — пригодятся надгробиям 26.2; ответы клиенту не меняются;
- новых событий и счётчиков нет.
