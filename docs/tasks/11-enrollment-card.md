# 11. Карточка брони (§4)

Без кэша.

- отменённая бронь отдаётся со статусом `cancelled`;
- бронь на отменённом занятии: при `Include(x => x.Class)`, а также при обращении к `x.Class`
  в `Select` или `Where`, фильтр выбрасывает саму бронь;
- чужая бронь → `404`;
- бронь, занятие, зал и абонемент — одним запросом (решение задачи 4): отдельные запросы
  при параллельной отмене смешают бронь до отмены с абонементом после.
