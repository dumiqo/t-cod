# 29.1 Контрактная матрица

Проверка обязательного функционала: на каждую строку каждой таблицы кодов и причин из
`ЗАДАНИЕ.md` — тест, плюс общие правила, которых в таблицах нет.

- результат — таблица «эндпоинт / строка контракта → тест» в этом файле; строка без теста —
  дописать тест. Большая часть строк уже покрыта тестами задач 8–28, задача — найти дыры, а не
  переписать покрытое;
- общие правила на всех восьми эндпоинтах: `401` без токена и с недействительным токеном
  (истёкший, чужая подпись, мусор), `429`, неизвестные поля тела игнорируются (у §1, §2, §7),
  отказ без следов на каждую причину отказа пишущих эндпоинтов;
- `429` на всех восьми уже есть (`RateLimit_61stOnEndpoint_Returns429WithoutTrace`), `401` —
  проверить, на всех ли восьми, а не на части;
- тесты на готовый код зеленеют сразу: красную фазу получаем, временно ломая реализацию
  (`CLAUDE.md`), в отчёте — прогон с поломкой и без;
- расхождение с контрактом, если найдётся, — тест-воспроизведение и исправление в этой же
  подзадаче, нюанс дописать сюда.
