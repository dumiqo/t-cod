# 23.3 Гонки и взаимоблокировка

- встречные отмены двух клиентов, каждый из которых ждёт на занятии другого: обе `200`,
  без `503`;
- отмена с продвижением против ухода из очереди (§8) и против постановки (§7): ушедший места
  не получает, порядок очереди сохраняется;
- отмена с продвижением против записи (§1) за те же места: мест не больше вместимости,
  посещения за бронь списаны один раз.
