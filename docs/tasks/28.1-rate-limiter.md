# 28.1 Ограничитель

- окно и хранение счётчика по решению задачи 27; место в конвейере, ключ, `429` — в [задаче 28](28-rate-limit.md);
- 60-й запрос проходит, 61-й — `429` по контракту; после перевода часов на новое окно —
  снова проходит; счётчики разных пользователей не смешиваются;
- запросы без пользователя не считаются; эндпоинты вне лимита — тест;
- считаются ли `400`, `403` и `404` — по решению задачи 2, тест на каждый;
- атомарность счётчика: 70 одновременных запросов одного пользователя — ровно 60 не-`429`;
- `429` — событие и `club.requests.rejected`.
