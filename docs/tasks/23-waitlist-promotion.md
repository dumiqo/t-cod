# 23. Продвижение очереди

При отмене (§3) и уменьшении мест (§2). Проверка абонемента ожидающего — по итогам
задачи 21. Тесты на гонки и взаимоблокировку.

По решению задачи 4: под замком занятия прочитать очередь, затем свой абонемент и абонементы
всех ожидающих — одним запросом `ORDER BY id FOR UPDATE`. Блокировка двух абонементов
отдельными запросами крест-накрест дала взаимоблокировку, одним запросом по id — нет (проверено).
Пачками в порядке очереди блокировать нельзя: пачки ломают общий порядок по id (пример —
в заметках). Тест на встречные отмены: обе проходят, без `503`.

События (задача 6): продвижение каждого ожидающего — событие с `waitlistId`, `enrollmentId`
и местами, `club.waitlist.promoted` и списание его посещений; после коммита операции, которая
освободила места.

Разбита на подзадачи 23.1–23.4, каждая — свой коммит и своя строка статуса, порядок по номерам.
Правила продвижения — по решениям задач 21 и 22. Продвижение встраивается в код задач 12 и 14:
их тесты без очереди должны остаться зелёными без изменений.

## 23.1 Продвижение при отмене (§3)

- под замком занятия: очередь, затем абонементы одним запросом `ORDER BY id FOR UPDATE` (выше).
  Свой абонемент входит в этот запрос: отдельный замок своего абонемента из 12.3 и 14.3
  заменяется, иначе общий порядок по id нарушен и встречные отмены дают взаимоблокировку;
- освободившиеся места уходят ожидающим по решению задачи 21; ожидающий становится активной
  бронью, его посещения списаны; в базе мест не больше вместимости, остатки не в минусе;
- бронь продвинутого — с id его записи в очереди (задача 18), первый тест подзадачи: до
  продвижения `GET /enrollments/{id из §7}` — `404`, после — `200`, точные `seats`,
  `status: active`, `createdAt` — момент продвижения (`app.Clock`), не время постановки;
  повтор §7 с тем же ключом после продвижения отдаёт тот же `id`;
- продвинутая запись очереди — `status = promoted` (задача 19), `cancelled_at` пуст; стоявшие
  за ней поднимаются; §8 по ней — `409 already-promoted`;
- ожидающий без посещений или с истёкшим абонементом; занятие отменено клубом или началось;
  место освободилось меньше чем за 2 часа до начала — по решению задачи 21;
- самопродвижение — по решению задачи 22;
- переполненное занятие (задача 1): если после отмены занятых мест не меньше вместимости,
  никто не продвигается;
- `refundedVisits` отменившего не зависит от продвижения.

## 23.2 Продвижение при уменьшении мест (§2)

- тот же код продвижения, что в 23.1; освобождается разница;
- самопродвижение при уменьшении — по решению задачи 22;
- ответ §2 — карточка уменьшенной брони, продвижение в ней не видно.

## 23.3 Гонки и взаимоблокировка

- встречные отмены двух клиентов, каждый из которых ждёт на занятии другого: обе `200`,
  без `503`;
- отмена с продвижением против ухода из очереди (§8) и против постановки (§7): ушедший места
  не получает, порядок очереди сохраняется;
- отмена с продвижением против записи (§1) за те же места: мест не больше вместимости,
  посещения за бронь списаны один раз.

## 23.4 Наблюдаемость

- на каждого продвинутого после коммита — событие с `waitlistId`, `enrollmentId` и местами,
  `club.waitlist.promoted` и `club.visits.charged`;
- при `503` и откате продвижения событий нет;
- тесты гонок 23.3 дополнить, как в 8.4: число событий продвижения равно числу продвинутых
  в базе.
