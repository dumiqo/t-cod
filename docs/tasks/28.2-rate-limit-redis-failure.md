# 28.2 Ограничение при отказе Redis

Поведение — по решению задачи 24 (заметки, раздел «Отказ Redis»).

- если по решению задачи 27 счётчик в Redis: при отказе Redis запрос пропускается, вызов идёт
  через «страж» из 26.4 (предел, фильтр исключений); тест с недоступным Redis — запрос сверх
  лимита проходит, тест с «зависшим» — ответ не позже `Redis:OperationTimeout`;
- событие 1004 Warning и `club.redis.failures` с `operation: rate-limit`, как в 26.4;
  `429` и `club.requests.rejected` при пропуске нет;
- если задача 27 оставит счётчик в памяти, подзадача закрывается без кода с пометкой «Redis
  не используется».
