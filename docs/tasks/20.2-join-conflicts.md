# 20.2 Причины 409 §7 и границы

- четыре причины, на каждую — тест, что отказ не оставляет следов (очередь, места, остаток);
- 6 пар причин по приоритету из задачи 3;
- границы `seats-available`: свободно ровно запрошенное число мест и на одно меньше; отменённые
  брони мест не занимают; `startsAt` равен текущему моменту и на тик позже;
- переполненное занятие (задача 1: свободных мест меньше нуля) — постановка проходит;
- `already-waiting`, повторная постановка после ухода и после продвижения, запрос больше
  вместимости, проверка абонемента — по решению задачи 19:
  - `already-waiting` — только при своей записи `waiting` на это занятие; отказ не оставляет
    следов; своя запись `waiting` на другом занятии и чужая на этом не мешают;
  - повторная постановка после ухода — `201`, новый id больше старого, `position` в конце
    очереди; после продвижения (запись `promoted`, есть активная бронь) — тоже `201`;
  - абонемент не проверяется (пометка `// решение:`): просроченный (`validUntil` вчера)
    и с нулём посещений — `201`, остаток посещений прежний;
  - запрос больше вместимости (`seats = capacity + 1`) — `201`, запись в базе (пометка
    `// решение:`).
